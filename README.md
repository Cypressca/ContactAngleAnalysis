# ContactAngleAnalysis

## 项目简介
`ContactAngleAnalysis` 是一个基于 MATLAB 的液滴接触角分析工具。程序会批量读取文件夹中的 `*.jpg` 图像，进行二值化与轮廓提取，自动寻找底部接触点，拟合液滴轮廓椭圆，并计算两侧接触角，最终输出可视化结果图和椭圆参数文件。

## 主要功能
- 批量处理指定文件夹内的液滴图像（`*.jpg`）。
- 交互式阈值调节（滑块），便于针对不同图像亮度进行分割。
- 形态学处理与最大连通区域提取，减少噪声干扰。
- 边界简化与角点检测，自动选取底部中间两点作为基线参考点。
- 对接触区域轮廓进行椭圆拟合（直接最小二乘法）。
- 计算拟合优度 `R^2` 并保存椭圆方程。
- 基于椭圆在接触点处的切线斜率，计算左右接触角。
- 生成包含原图、灰度图、分割结果、拟合曲线和角度标注的结果图。

## 核心流程
1. 选择包含图像的文件夹。
2. 逐张读取 `*.jpg` 图像并转灰度图。
3. 通过滑块交互设置二值化阈值。
4. 执行孔洞填充、开运算、最大连通域提取。
5. 提取边界并检测角点，选取底部两个中心点构建基线。
6. 在两接触点之间的较短边界段上拟合椭圆。
7. 计算拟合优度 `R^2` 与左右接触角。
8. 输出图像结果和文本参数结果到 `results/`。

## 运行环境
- MATLAB（建议安装 Image Processing Toolbox）

## 使用方法
1. 在 MATLAB 当前路径中打开本仓库。
2. 运行：

```matlab
ContactAngleAnalysis
```

3. 在弹窗中选择包含液滴图像的文件夹。
4. 每张图会弹出阈值窗口，调节后关闭窗口继续处理。

## 输入与输出
### 输入
- 图像格式：`*.jpg`
- 输入目录：用户在运行时选择

### 输出
程序会在输入目录下创建 `results/`，并生成：
- `*_result.png`：可视化结果（角点、基线、拟合椭圆、接触角、`R^2`）
- `*_ellipse.txt`：椭圆方程与 `R^2` 数值

## 代码结构
- `ContactAngleAnalysis.m`：主入口与完整处理流程
  - `ContactAngleAnalysis`：批量读取并调度处理
  - `processImage`：单图处理、拟合、角度计算
  - `visualizeResults`：结果可视化与保存
  - `findLargestRegion`：提取最大连通区域
  - `detectCorners`：边界简化与角点检测
  - `fitEllipse`：椭圆拟合与参数解析

## 注意事项
- 当前代码实际读取 `*.jpg` 文件；错误提示文案中“TIFF”仅为文字遗留，不影响功能。
- 若图像质量较差或阈值不合适，可能导致接触点识别或拟合失败，此时接触角结果为空。
- 项目中打包生成的可执行文件属于构建产物，不建议纳入版本控制。
